============================================================
  [사용법]
  1. 내 문서\TypingLog 폴더에서 typing_YYYY-MM-DD.txt 파일(들)을 첨부
     (영문이 깨져 있으면 raw_YYYY-MM-DD.txt 도 같이 첨부)
  2. 아래 ▼▼▼ 프롬프트를 복사해서 타 AI에 붙여넣고 파일과 함께 전송
  3. AI가 준 목록을 복사해서 →  내 문서\TypingLog\phrases.txt  로 저장
  4. 자동완성 앱이 phrases.txt 를 자동으로 읽어 동작 (저장만 하면 바로 반영)
============================================================

▼▼▼ 여기부터 복사 ▼▼▼

첨부한 파일은 내가 Windows에서 실제로 타이핑한 기록이야.
- 한글은 자동 조합된 상태라 오타나 조합오류가 있을 수 있어.
- 한/영 모드 구분이 안 돼서 영문이 한글로 깨져 나온 부분도 있어
  (raw 파일에 원본 키가 들어있으니 그걸로 복원해줘).

아래 작업을 해줘:
1. 오타·조합오류·깨진 영문을 문맥에 맞게 교정해서 자연스러운 문장으로 복원.
2. 다음은 전부 제외: 의미 없는 입력(탐색키·한두 글자·UI 메뉴 텍스트),
   중복, 그리고 개인정보(비밀번호, 카드·계좌번호, 주민번호, 로그인 정보 등).
3. 내가 자주 쓰는 표현·문장·구문을 뽑아서 중복 제거.
4. 자주 쓸 것 같은 순서(빈도 높은 순)로 정렬.

출력 형식 — 아래 규칙을 반드시 지켜줘:
- 설명, 머리말, 번호, 따옴표, 마크다운 없이 "표현 목록만" 출력.
- 한 줄에 표현 하나.
- 가능하면 완결된 문장/구문 위주 (자동완성에 바로 쓸 거라서).

출력 예시:
안녕하세요 반갑습니다
확인 후 다시 연락드리겠습니다
감사합니다 좋은 하루 보내세요
오늘 회의는 오후 3시에 시작합니다
지금 확인하고 바로 회신드릴게요

이 목록을 그대로 phrases.txt 로 저장해서 자동완성 기능에 쓸 거야.
